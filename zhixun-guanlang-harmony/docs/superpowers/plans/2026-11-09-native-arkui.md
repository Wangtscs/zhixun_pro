# 纯 ArkUI 手机端重构计划

用户已要求立即执行上一轮提出的纯 ArkUI / ArkTS 方案。

目标：保留 Figma 工人端界面与演示流程，将鸿蒙应用从 ArkWeb 混合实现改为原生组件。

架构：单个 entry 模块，pages 仅负责导航组合；features 按 auth、inspection、orders、assistant、profile 分区；common 放颜色、图标和公共控件；models 定义数据；services 提供演示数据。原稿源码保留为参考，不再参与应用构建。

- [x] 原生工单和助手，导航和返回行为。
