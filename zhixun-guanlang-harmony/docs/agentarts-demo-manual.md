# 智巡管廊比赛演练手册

本文使用虚构舱室与模拟告警，仅用于比赛演练和知识库检索验证。真实事件由现场值班负责人按正式应急预案处理。

## A-01 演示舱 A 气体传感器告警

适用告警：模拟告警，演示舱 A 的气体传感器触发告警，读数和单位暂缺。

告警研判：已知设备发出告警。记录触发时间、舱室和设备编号。读数、单位、监测气体和规则等级缺失时分别标记待核实。

抢险处置建议：把模拟告警记录交给演练值班员，由值班员核对传感器编号、读数、单位和告警等级。确认后将演练记录更新为“已核对”。演练核对编号为 GL-A01。

出处：《智巡管廊比赛演练手册》A-01 演示舱 A 气体传感器告警。

## B-01 演示舱 B 阀门压力波动

适用告警：模拟告警，演示舱 B 的阀门压力出现波动，告警等级待确认。

告警研判：记录阀门编号、波动起止时间、压力读数和单位，沿用系统已给出的告警等级。等级缺失时标记待确认。

抢险处置建议：由演练值班员核对压力记录和仪表状态，确认是否需要补充演练工单。演练核对编号为 GL-B01。

出处：《智巡管廊比赛演练手册》B-01 演示舱 B 阀门压力波动。
