# Figma Make 交互补齐与设备复验

日期：2026-11-10。基准为本地 `design/figma-source/src` Make 源码中的实际事件与状态逻辑。本轮已修改原生 ArkUI，实现不依赖网页运行时。

后续安全区修正：找回密码标题原先顶部为设备像素 y=63，进入摄像头区域；现读取窗口挖孔/系统避让区并动态留白，设备复验标题顶部为 y=183，摄像头预留为120px。重新编译安装通过，证据为 `2026-11-10-runtime/recovery-safe-top.png` 及同名布局 JSON。下述 HAP 哈希对应此前交互补齐包，安全区修正版为其后续构建。

## 已实施

- 登录支持字母数字工号、聚焦边框与加载动画；找回入口/联系管理员/返回；身份卡片、绑定手机、工号错误；六格验证码、59 秒倒计时、重发、3 次错误限制；三条密码规则、密码显隐、不一致与成功页。
- 验证码原先使用六个原生输入框，在模拟器连续输入时发生焦点竞态。本轮改为一个原生编辑框接收输入并绘制六个格子，避免重复数字丢失。原生编辑框保留读屏标签，装饰格不重复参与读屏。
- 透视节点点击后打开覆盖底栏的全屏遮罩/底部抽屉，显示位置、状态、甲烷/温度/健康度；遮罩、关闭按钮、硬件返回和查看详情均接入。报修抽屉带当前节点上下文。
- 通知筛选、单条已读/全部已读、详情底部抽屉；设置分组、开关、免打扰暂存保存、15/30/60 秒重连暂存保存、清理缓存、账号信息抽屉。
- 恢复六条 FAQ、默认首项展开、问题与答案搜索/清空/空状态；反馈抽屉→预览→完成清空，客服和电话说明抽屉；关于品牌与四份原稿文档抽屉。
- 工单恢复原稿任意进度可上报，保留当前进度；上报仅禁用上报按钮。摘要改为两列两行、实心勾选、列表统计左对齐和青色全宽进度。
- 页面/硬件返回先关闭当前抽屉；找回密码结束时清理登录密码和错误信息。

严格沿用 Make 的演示语义：退出登录按钮打开账号说明，不实际注销；工单列表固定演示值，详情重入重置；扫码、企业微信、客服、电话及重置密码不接真实服务。旧 TaskRepository 仍保留但已不参与活动工单 UI，其单测不证明 UI 的上报/重入行为。
