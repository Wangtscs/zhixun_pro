# Figma layout verification

The 41 reference screenshots are stored only in tmp/figma-references for comparison. Application source must not import those images or use a Figma full-page image as a page background.
Core pages use a 72px rail and 72px header, 24px main padding, 132px metric cards, 18px panel radii, and the dark/teal palette in src/design.css and workspace.css. Data remains dynamic; screenshot text such as names, timestamps and counts is supplied by the isolated demo only.
