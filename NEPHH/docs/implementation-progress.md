## 文件入口

- NEPHH-backend/src/main/java/com/nephh/business/：权限、基础数据、数据上报、告警、工单、巡检、附件、通知、审计、报表和定时任务。
- NEPHH-backend/src/main/resources/db/migration/V2至V6：增量迁移；db/schema.sql为完整结构参考。
- NEPHH-Admin/src/components/Workspace.vue、workspace.css：真实业务工作台与移动布局。
- NEPHH-Admin/src/business.ts：业务请求、认证附件读取与显示字典。
- NEPHH-backend/README.md：启动、使用步骤、查询范围、验证方式。
- docs/integration-contracts.md：硬件数据格式、设备映射、Agent结果与工具接口的预留契约。

## 明确边界

- 数据来源为模拟器，告警由规则生成，页面未声称完成AI推理。
- 没有做真实设备/华为IoT联调，也没有做24小时压力或通宵稳定性测试。
- 附件使用本地目录存储，需随数据库一起备份。
- 列表数量上限及报表导出范围已在后端README中说明。
- 集成验证会产生带验证标识的演示记录；测试账号和计划在脚本正常结束时停用。
- JWT无服务器撤销和刷新令牌；当前业务接口仍会拒绝已禁用账号。
