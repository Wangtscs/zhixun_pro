本次按现有功能收尾。当前版本可用于软件流程演示和前后端联调；硬件、华为IoT和Agent仍未接入。页面已依据设计稿重建为可交互组件，未承诺与原稿逐像素一致。

主界面保留总览、节点、工单、审计和个人设置入口；更多业务入口在用户菜单的“系统设置”中，按账号权限显示。

## 工人管理方法

1. 使用管理员账号登录真实环境。
2. 打开右上角用户菜单 → 系统设置 → 用户权限。
3. 新增账号，角色选择巡检员，设置账号和密码。
4. 在“权限与区域”中分配该工人可处理的区域，并保持账号启用。
5. 值班长派单时选择该区域内启用的巡检员；工人用自己的账号登录后接单和处理。

只在角色菜单切换视图不会创建工人，也不会赋予管理员权限。演示环境内的人员和修改不会保存到真实数据库。

## 可演示的业务流程

管理员建工人并分配区域 → 配置节点和告警规则 → 模拟异常上报 → 产生告警 → 创建/派发工单 → 巡检员接单、处理并上传记录 → 值班长复核 → 查询时间线、审计及报表。

独立演示模式可直接查看页面和交互。真实多账号流程需要启动后端和数据库，并分别使用有权限的账号登录；当前记录不代表本轮重新完成了所有浏览器流程测试。

- 华为IoT/MQTT真实连接、设备认证、属性映射和单位转换：仅预留平台绑定字段和统一数据入口。
- 实体传感器、机器人、摄像头、自动识别与远程控制：未接入。管廊图是二维示意，不是实时三维数字孪生。
- Agent/大模型分析、风险预测、智能解释与自动决策：未实现；预留分析结果结构和关联字段。
- 二次验证、短信/邮件通知、刷新令牌、审计防篡改完整性验证：未实现。声音和桌面通知仍需真实浏览器端到端验证。
- 派单候选展示及任务数不等同于智能调度优化；抢单模式开关不能代表一套完整的抢单业务已经上线。
- 原稿41个状态的逐像素一致性未验收；部分字体、图标、蓝图为现有实现。

## 部署和维护范围

前端Vue 3/TypeScript/Vite；后端Java/Spring Boot；MySQL与Flyway迁移。头像和工单/巡检附件保存在后端本地上传目录，备份时需要同时备份数据库与附件。现有版本尚未完成生产部署、安全加固及真实硬件长时间运行验收。

启动方式见前后端README；未来接入约定见integration-contracts.md；设计状态的历史核对记录见figma-state-audit.json。
