# T07 视觉规范集成与实测

状态：已集成并完成本轮抽样视觉和交互验证，待主代理审查提交。不是像素一致性或全量无障碍认证。

## 环境与方式

- Node24.22.3、可见Edge146、Vite5174；截图全部使用独立演示数据，业务API阻断，硬件桥使用断开样本。
- 通过真实“个人设置 / 外观设置 / 日间模式或夜间模式”按钮切换，不注入主题存储或DOM样式。
- 深浅两种主题、1440/900/390三种宽度、总览/节点表/派单抽屉/工单详情四类视图，共24组合。
- 对明确选择器读取计算字号、前景和背景；检查页面运行错误、横向滚动、键盘焦点、抽屉滚动与按钮命中。不将这些抽样推断为全站每个文字均已覆盖。

## 发现与定点修复

- 旧节点健康分9px、说明/单位8px、读数10px未随表格正文继承放大；分别改为辅助12px和主要读数14px。
- 派单搜索仍11px，改为14px；候选职责标签补为12px。
- 工单摘要10px、字段标签9px和字段值10px分别补齐12px/14px；浅色字段值不再保留暗色旧灰。
- 来源文字随字号增大挤入下一列，读数单元格使用局部网格，来源标签单独一行。
- 健康分内层背景改用当前主题表面色，避免浅色主题保留深色圆底。

所有修复只在`operations-theme.css`内增加精确作用域选择器，没有修改业务Vue组件、权限、网络或状态机。

## 实测结果

- 24组合通过，页面脚本异常0。
- 抽样主要正文最小14px，辅助文字最小12px。
- 900和390宽度节点表格出现容器横向滚动，真实水平滚轮改变scrollLeft；不靠压缩字号塞入。
- 从搜索框按Tab进入后续控件，`:focus-visible`出现solid外轮廓。CSS定义3px；当前系统缩放下浏览器计算宽度约2.4px，实际可见。
- 派单抽屉可滚动，选择候选后确认按钮可用，命中测试没有被浮层覆盖；正常取消可关闭。
- 真实local/H2正式工单脚本再次通过：管理员派发、巡检员接单/开始/图片上传/提交、管理复核、巡检员刷新COMPLETED，页面异常0。
- 最终`npm run build`：类型检查和生产构建通过。
