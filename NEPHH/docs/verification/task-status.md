## 本轮环境

- Java：JDK 21 / Maven 3.9.8。全局Maven配置会覆盖release为8，本轮命令显式 `-Dmaven.compiler.release=17`。
- Java隔离服务：local/H2，显式清空外部配置导入，独立18081端口，禁用华为IoT；不访问现有MySQL库。
- 网页：Node 24.22.3，官方便携版本并校验SHA256；独立5174端口代理隔离API，硬件桥验证使用隔离响应。
- 鸿蒙：DevEco Studio 6.0.2 / API22，原生构建通过；没有API22兼容在线设备。设备交互、签名安装与真实双端联调保持未验收，见鸿蒙基线记录。

## 基线缺陷修复

完整后端测试暴露生成主键读取缺陷：H2默认返回id和created_at，通用getKey不能读取多列。最小修复限定请求id列，不改变调用签名、SQL或状态机；新增5项JUnit，涵盖多驱动标签、数字类型、异常返回、真实H2默认值及事务回滚。修复后33项测试和打包通过。

任务提交的准确SHA通过 `git log --format='%h %s%n%b'` 查询，提交正文记录对应Task编号；不在同一提交中写入自身尚未生成的SHA。
