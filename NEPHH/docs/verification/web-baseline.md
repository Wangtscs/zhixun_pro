# T01 网页环境与截图基线

状态：构建、现有单元测试及演示页面导航已验证；真实业务闭环由后续隔离环境测试验证。

## 环境

- Node.js v24.22.3，官方便携发行包，已与官方 SHASUMS256 校验。不修改系统运行时或项目依赖版本。
- 项目声明允许 Node 24.12 起，但当前锁文件中的部分工具要求 24.15 起；24.12 初轮出现 engine 警告，因此最终结果统一使用24.22.3。
- Microsoft Edge 146，Playwright 使用可见浏览器，窗口1440×900。
- Vite 专用地址 `http://127.0.0.1:5174`，后端代理指向隔离服务18081，未使用8080。
- 截图浏览器上下文拦截全部业务 API，并将硬件桥替换为503断开状态。页面数据来自独立内存演示，未读取真实账号、硬件或数据库。

## 实际验证

1. 使用受支持Node执行 `npm ci --ignore-scripts --no-audit --no-fund`：成功，锁文件未修改。
2. `npm run build`：类型检查通过，Vite生产构建通过。
3. `node --test tests/*.test.mjs`：7项通过，0失败。
4. 实际打开登录页，收起硬件浮层，点击“预览平台”，进入总览；通过侧栏点击节点管理、工单管理、个人设置。
5. 页面脚本异常0，非GET网络写请求0。未使用强制点击或直接注入登录状态绕过交互。

## 当前可复现问题

登录页硬件面板默认展开。在1440×900窗口，面板正文覆盖“预览平台”按钮，正常指针点击被拦截。先点击“收起采集面板”后，可正常进入演示。该问题已记录，截图成功不代表原始遮挡问题已修复。

演示总览显示“实时连接”和固定更新时间，不能据此证明连接真实后台。演示个人设置包含预置身份资料；截图不是实际用户信息。

## 验证边界

这些证据只验证当前演示入口和主要页面可交互。没有证明真实派单、巡检、复核、全部设计状态、移动适配或像素一致性验收通过。隔离API业务流程、角色权限和后续视觉修改分别验证并记录。
