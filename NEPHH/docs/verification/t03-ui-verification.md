## 隔离要求

所有脚本显式指定 `UI_BASE`，真实接口脚本另需 `API_BASE` 和管理员环境变量。地址限定loopback专用端口，拒绝远程主机和8080/5173等常用业务端口。

真实接口脚本同时核对直连API和网页代理健康响应的 `data.isolatedVerification=true`。该标记仅由显式verification-mode且实际local/H2的服务提供。写入脚本还要求 `ALLOW_ISOLATED_WRITES=1`。
