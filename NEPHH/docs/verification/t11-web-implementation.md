# T11 告警详情实现检查

告警列表、待办紧急告警、关联消息使用告警ID打开独立详情。详情通过授权接口读取，展示持久化原因、确认和恢复时间、当前规则及其非历史快照说明、带来源/采集时间的最新读数和明确alarm_id关联工单。无关联如实提示；超过100条显式提示更多。关联工单沿用原详情和时间线，管理者可预填创建关联工单，巡检员与只读无建单按钮。

加载/失败/重试、旧快照提示、失权清空、过期请求隔离、关闭及焦点恢复均有代码实现。它们尚未在浏览器实际操作，不以代码实现宣称交互通过。

检查：vue-tsc --build通过；vite build通过；alarm-detail-demo.test.mjs 1项通过，证明打开详情不自动确认告警，创建后只通过明确alarm_id关联，其他告警不串单，缺失ID为404。后端7项和HTTP证据见t11-alarm-api.md。

用户选择继续代码/API且不切回本任务，不尝试控制窗口，不打开外部浏览器、不启动鸿蒙虚拟机。网页交互、双主题、键盘/返回与真实设备链路待验收。
