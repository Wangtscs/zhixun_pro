## 实现边界

- `history-series.ts`按指标处理原始历史记录；`TelemetryHistoryChart.vue`输入rows、metrics、rules、reportSeconds，不发请求、不修改数据、不使用新增依赖。
- 横轴为有效`collected_at`实际时间间隔。时间必须带显式时区，非法日历日期与模糊本地日期不绘制，不拿接收时间或当前时间替换。
- 每个指标独立图表和单位。负值与大于100的值保留；纵轴根据样本及可显示阈值动态扩展，不裁到0–100。
- 缺失/非法值形成断点；相邻有效采样超过三个上报周期时断线。真实零值保留，缺数不补零。
- 同指标同采集时间优先保留最大有效记录ID，与最新读数接口的ID排序一致；没有有效ID时明确按输入数组最后记录兜底。较新记录为缺值时保留断点，不能恢复较旧有效值；重复数量明确显示。
- 有效数值样本单位冲突或缺失时提示且不混画，不进行隐式单位换算。
- 阈值仅在规则明确启用、数值有限且单位与该指标配置一致时显示。虚线和文字均标“当前配置”，不伪称历史触发规则快照；纵轴将有效阈值纳入范围。
- 图例复用source-status分类，分别显示模拟、实测、平台上报待确认、未知来源及原始source。平台名字不证明实测。
- 空图不生成假曲线；输入达到5000条时明确提示可能截断。时间窗口按本次实际可确认样本表示，不冒充用户请求完整范围。
- SVG坐标文字12px；图表最小宽760px，窄窗口横向滚动，不将文字压缩。滚动区可键盘聚焦。

## 已执行验证

9项模型行为测试通过，覆盖：

1. 不等距时间位置、负值及大于100的有效值。
2. 显式缺值、非法值、恰好三周期保持相邻、超过三周期断线。
3. 同时间最大有效ID覆盖，不受历史接口同时间倒序输入影响；无ID才按最后输入兜底；较新缺值不能恢复旧值，字符串大ID保持精确比较。
4. 非法、无时区和非法日历日期不伪装当前数据。
5. 单位冲突、单位缺失不混绘。
6. 启用/停用/非法阈值、阈值超出样本范围及单位不兼容。
7. 指标、量纲、模拟/实测/平台/未知来源分离。
8. 空数据与有效零值不同；极大有限数值的归一化保持有限。

另有5项周图行为测试通过：真实0保留、planned/completed独立使用、数字旧格式不推算缺失项、非法百分比不强裁或补0、缺失周不制造12个零值，以及演示统计明确提供虚构对象数据。合计14项测试通过，网页类型检查通过。以上不是浏览器交互或真实历史接口验收。

## 周图修正与接口限制

- `ReportChart.vue`移除`completed=planned-13`和缺失字段补0。只绘制服务端显式提供的有限0–100百分比；缺失或非法项显示未知，真实0单独保留。
- `weekly-report.ts`整理输入结构，保留服务端标签；缺失标签明确说明，不伪造W1–W12。组件提供可展开数据表，屏幕阅读与缺失项可核对。
- 当前真实ReportController返回12项`label/planned/completed`。planned/completed的分母是当前启用节点数，并非各周任务数；组件据此称“计划/已检查节点覆盖率”，不称任务完成率。
- 当前接口没有实际周起止与历史分母，组件明确提示服务器周序号、日期未提供，不按浏览器当前日期推算。要增加实际周日期须由服务器另供字段。
- 演示`/statistics`改为明确`demo:true`和虚构对象数组，每项planned/completed独立给值。真实渲染器不包含演示曲线或统计生成分支。

2. 新组件输入：rows取`history`；metrics取当前单选指标数组，选全部时使用节点声明指标；rules取完整`nodeRuleSettings`，不能只传阈值数值；reportSeconds取节点上报周期。示例：

   ```vue
   <TelemetryHistoryChart
     :rows="history"
     :metrics="historyMetric==='all' ? String(selectedNode.metrics||'methane,temperature,humidity').split(',') : [historyMetric]"
     :rules="nodeRuleSettings"
     :report-seconds="Number(selectedNode.report_seconds)||30"
   />
   ```

3. 打开新节点时，先清`history/nodeThresholds/nodeRuleSettings`。规则请求同样需要revision/nodeId核对，不能在新节点短暂显示旧节点阈值，或允许过期规则请求回写。巡检员无规则权限时明确未配置/不可确认，不保留前一账号规则。

5. 周图调用增加`:demo="isDemo"`。外层标题改为“近12周节点覆盖”，图例使用“计划节点覆盖率”“已检查节点覆盖率”，与组件及服务器口径一致。
