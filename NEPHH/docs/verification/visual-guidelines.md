# T07｜工业工作台视觉规范

状态：样式已在正式应用入口末尾集成，并完成可见浏览器深浅主题、三种宽度、四类主要视图的抽样验收。详见 [T07实测记录](t07-visual.md)。不宣称像素还原、全量页面或全量可访问性验收通过。

## 使用范围

样式入口为网页源码中的 `operations-theme.css`。应在既有workspace、design及light-theme样式之后导入；所有规则限定于 `.design-app`，不覆盖登录界面和同级硬件采集面板。当前不修改Vue、业务逻辑、权限或任务状态。

这是一层定点整理，不重写原有页面结构。若旧规则带有高优先级或行内样式，先确认具体控件再调整；禁止用全站字号强制覆盖掩盖问题。

## 视觉准则

| 项目 | 规范 |
| --- | --- |
| 方向 | 克制工业工作台：清晰层级、适度密度、证据与动作优先，减少无业务含义的装饰 |
| 正文 | 14px，行高至少1.5；重要卡片标题14px，面板18px，页面22–26px |
| 辅助 | 标签、单位、时间、表头、提示至少12px；不能通过缩小字号硬塞内容 |
| 数字 | 指标和时间使用等宽数字；单位12px与数值保持明确间距，不把不同量纲混为百分比 |
| 间距 | 8 / 12 / 16 / 24px；工具栏、列表、抽屉和内容组采用相同节奏 |
| 表格 | 表头12px、正文14px；行高随内容自适应，保留横向滚动；窄屏不压缩为不可读文字 |
| 表单 | 正文输入14px、最小高度40px；按钮文字至少12px；禁用保留可辨识文字 |
| 交互 | 青色为主操作和选中，状态同时显示文字；焦点3px外描边，可与鼠标悬停区分 |
| 色彩 | 红色为紧急/错误，黄色为预警，灰色为离线/未知；蓝色用于信息。暗色、浅色分别设前景与背景，不直接复用暗色文字 |
| 抽屉 | 默认最大560px；标题、正文、脚注明确分区，正文可滚动，滚动条可见；窄屏页脚可折行 |
| 动效 | 只作反馈，尊重减少动态偏好；加载中用状态表达，不隐藏错误或替代结果文字 |

颜色变量以 `--ops-*` 命名，由工作台作用域拥有。已有通用变量只在该作用域映射。颜色只是视觉语义，不承担告警恢复、数据真实性或权限判定。

## 已定点覆盖

- 页面标题、说明、更新时间、连接提示。
- 指标卡片标签、单位和数字排布。
- 节点/工单/审计表格、筛选工具栏、搜索和分页。
- 告警卡片、工单卡片、状态标签和处置时间线。
- 派单候选、已选人员、截止时间选项及抽屉脚注。
- 个人设置常用标题、说明及表单。
- 聚焦、禁用、加载和窄屏滚动。

## 浏览器核对清单

1. 深浅主题分别打开总览、节点、工单、审计、设置，核对主要文字计算字号与前景/背景。
2. 1440、1024、窄窗口分别检查表格横滚、工具栏换行、图标按钮与输入框，不允许主要动作被遮挡。
3. 打开节点和派单抽屉，核对候选说明、任务量、单位、截止时间、页脚和滚动区域；不因增大字体导致按钮离屏不可达。
4. Tab键进入输入、筛选、表格操作及抽屉，检查焦点可见；样式本身不替代抽屉焦点管理。
5. 记录禁用、提交中、错误和空态；不以截图看起来完整替代真实可交互验证。
6. 检查登录页和硬件面板不受工作台规则影响。
7. 检查图表SVG文字实际渲染尺寸。图表量纲、轴、阈值和缺数属于T13，不能只放大样式就宣称数据表达已正确。
8. 对旧样式中的重要声明与行内样式做局部核对；若冲突必须缩小修复范围，不添加全局字号强制规则。

原型只提供视觉方向。没有执行用户访谈、对比度测量或全量可访问性审计时，不宣称这些验收已通过。

## 本轮核对结论

- 通过实际个人设置的日间/夜间按钮切换主题；1440、900、390宽度分别检查总览、节点列表、派单抽屉、工单详情，共24组合。
- 抽样主要正文计算字号至少14px，辅助文字至少12px；旧嵌套字号已做精确选择器修复，没有全站强制字号覆盖。
- 发现节点来源标签随字号增大会横向挤入下一列，已将读数单元格改为局部网格，来源占独立一行；浅色健康分内层与工单字段颜色已改用对应主题变量。
- 窄窗口表格可通过横向滚轮滚动；键盘Tab焦点可见；派单抽屉正文可滚动，页脚按钮可正常点击。
- 真实local/H2工单完整UI流程重新验证通过，未使用force点击。
- 图表轴、地图注记、完整状态集合、对比度及读屏审核仍按后续任务分别验收。
