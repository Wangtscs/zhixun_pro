# 鸿蒙源码基线验证

验证日期：2026-11-20。状态：原生构建和设备外测试通过；设备交互、签名安装和真实业务联调未通过本轮验收。

## 已完成的配置整理

- 公开应用构建配置移除本机证书、私钥路径、签名密码及产品签名引用；保持 HarmonyOS 6.0.2 / API 22。
- 原有本机签名配置备份为被 Git 忽略的 `build-profile.local.json5`。未删除本机材料，未将其加入公开文件。
- 构建脚本支持显式 `-DevEcoHome`、环境变量 `DEVECO_HOME` 和 DevEco 安装记录自动发现。SDK、JBR、Node 使用同一 DevEco 安装目录，源码不绑定提供者电脑的旧盘符。
- 默认无签名构建；显式 `-UseLocalSigning` 才临时使用本机签名配置，并在构建结束或异常时恢复公开配置。说明同步到手机端 README。
- 本机 SDK 路径通过被忽略的本地配置修正，未作为公开 SDK 路径提交。

## 警告与限制

- 原生全量编译有一条既有ArkTS警告：入口生命周期中同步取得主窗口的调用可能抛出异常。当前未修复该业务源码，本轮不宣称“零警告”。
- `No signingConfig found for product default` 是默认无签名构建的预期提示，不表示已经完成发布签名。
- HDC在线设备列表为空。本机已配置的模拟器最高为API 21，另有API 20和16；应用最低兼容API为22。未为测试而降低SDK要求，未启动不兼容模拟器。
- 本轮没有兼容的在线模拟器或真机，因此没有安装、登录、页面返回键、弹层、照片选择、录音朗读或真实业务写入验证。
- 未使用原有本机签名材料进行签名安装；保留它们不能证明材料在当前机器有效。
- 当前移动网关地址仍是既有局域网验收地址。本轮没有将真实登录或业务写入指向生产环境，也没有把Node测试当作真实上游联调。
