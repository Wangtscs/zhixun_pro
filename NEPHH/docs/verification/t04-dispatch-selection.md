# T04 单张工单的执行人选择

状态：实现与隔离验证通过，待主代理审查提交。

## 改动

- 新增独立派单规则：仅返回已启用、角色为INSPECTOR且已授权目标区域的用户；缺失或非法区域返回空列表。
- 去掉候选前十人截断，增加姓名或账号搜索。按姓名稳定排序，移除“按当前任务量排序”的未实现承诺。
- 打开单单派发时从工单区域或关联节点解析区域，过滤已失效的历史选择；缺失区域不能派单。
- 点击候选和提交单单派发时再次核对1至2人及区域合法性；服务器原有最终鉴权不变。
- 候选显示真实授权区域，去掉原先区域缺失时默认展示A区的回退。
- 规则接口接收区域数组以复用实际批量需求，但本任务仅从单单区域传入；批量区域交集和提交策略留待T05。
