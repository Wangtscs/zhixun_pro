# T09 主要读数与来源标签的一致性

状态：代码、定向单元测试及类型检查通过；浏览器真实交互待Codex内置浏览器验证，不能标记T09整体验收完成。

## 改动范围

- `metric-reading.ts`复用统一`assessSample`判断。甲烷、温度、湿度、红外等主要读数必须是有限数字、带明确时区的采样时间且未超过三倍上报周期，才返回原采样行。
- 演示标志不再绕过数值或时效校验；真实0保留，空值、数字字符串、NaN、Infinity不变成有效读数。
- 模拟样本在满足时效时可见，来源标签通过`classifySource`直接分类。平台模拟、设备模拟甲烷、平台上报及来源待确认不会被统一叫成“主控上报”。
- 来源标签独立于值的时效：即使主要读数已过期隐藏，仍可说明它原本来自模拟或其他来源，避免丢失数据性质。
- `verify-live-ui.mjs`的隔离刷新样本补齐明确`source`、`collected_at`、`received_at`，不再依赖缺时间的读数也可展示的旧行为。仅做语法检查，没有启动该浏览器脚本。

没有修改Workspace、App或逐项来源面板；界面标记与面板集成由主代理负责。
