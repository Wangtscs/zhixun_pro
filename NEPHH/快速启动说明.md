# 智巡·管廊本地启动

双击桌面上的 `启动智巡管廊.cmd`。启动器会检查并启动后端和前端，等待连通后打开：

http://127.0.0.1:5173/login

重复启动会复用现有服务；关闭浏览器后服务继续在后台运行。本启动器仅监听本机，不开放局域网或公网访问。

## 文件位置

- 桌面入口：`启动智巡管廊.cmd`
- 启动程序：`NEPHH/start-nephh.cjs`
- 服务日志与运行缓存：`NEPHH/.nephh-runtime/`
- 后端日志：`backend.stdout.log`、`backend.stderr.log`
- 前端日志：`frontend.stdout.log`、`frontend.stderr.log`（仅记录由此启动器新启动的进程）

## 登录与演示

正常登录使用项目已有账号。未持有账号时，可以点击登录页的“一键进入演示环境”查看界面；这是项目原有的独立演示数据。

本启动器沿用后端现有数据库配置，不初始化、清空数据库或创建账号；应用自己的正常启动流程仍会执行其数据库迁移和定时任务。

## 实现说明

前端使用已有 Node.js 和 Vite 依赖。后端使用电脑上 Java 17 或更高版本、项目已有的 `target/classes` 编译文件，以及从现有 JAR 中提取的第三方依赖。没有重新下载或构建整个项目。

后端源码修改后需重新编译 `target/classes`；前端源码支持 Vite 热更新。请保留整个 NEPHH 文件夹和其中的 node_modules、target 及本地配置文件。

终端内运行 `node start-nephh.cjs --no-browser` 可以检查并启动服务，不额外打开浏览器。
