# 智巡管廊后端

Java 17+ / Spring Boot / MySQL 8 / Flyway。当前实现网页版管理端与巡检员端的业务接口，硬件和 Agent 尚未接入。

鸿蒙 App 开发交接请阅读 [鸿蒙App后端对接文档](../docs/鸿蒙App后端对接文档.md)，完整控制器接口见 [接口索引CSV](../docs/backend-api-index.csv)。

华为IoTDA主动读取适配层已预留，默认关闭；配置与同步接口见 [华为IoT接入说明](../docs/huawei-iot-integration.md)。目前支持部署侧提供IAM Token，尚未连接真实平台，也未实现Token自动续期。

## 本机启动

1. 在 IDEA 中以 Maven 项目打开本目录，选择 JDK 17 或 21，重新加载 Maven。
2. 本机数据库配置位于 `.local-database.yml`，已被 `.gitignore` 忽略。普通启动会自动读取它并启用 `mysql` 环境。
3. 运行 `com.nephh.NephhApplication`，默认端口8080。也可执行 `./start-local-mysql.ps1`。
4. 启动前端：进入 `../NEPHH-Admin`，运行 `npm run dev`，默认地址 `http://localhost:5173`。

没有 `.local-database.yml` 时默认启用 `local`：使用H2内存数据库。新机器复制 `.local-database.example.yml` 为 `.local-database.yml`，填写实际凭据；数据库需事先创建为空库。Flyway自动应用V1至最新迁移，不要手工重复执行 `db/schema.sql`。

首次创建管理员可设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD`（至少12位，最多72字节）。仅用户名不存在时创建，不覆盖已有账号。已有账号通过“用户权限→重置密码”修改。密码保存为BCrypt哈希。

## 已实现

- 账号：管理员、值班长、巡检员，账号禁用、密码重置、区域授权；每次业务请求查询数据库校验当前权限。
- 基础数据：管廊、区域、区段、节点、负责人、监测指标、设备平台绑定、节点坐标、维护/启停状态。
- 监测：统一上报、消息去重、历史查询、模拟场景、数据来源、最新读数及二维管廊图。
- 告警：指标阈值、连续异常时间、三倍上报周期离线、恢复时间、人工确认；规则为演示配置，不是AI分析。
- 工单：新建、派发/改派、接单、开始、结果/照片、提交复核、退回、通过、取消、事件时间线。
- 巡检：周期计划、检查点及检查项目、自动或手动生成任务、逐点检查和照片、异常转工单。
- 协作：站内通知、已读状态、逾期提醒、操作审计；值班长查看本人及授权区域日志，管理员查看全部日志。
- 报表：区域和时间筛选、工单状态、告警级别、响应时间、逾期数、重复告警点、计划点位覆盖率、CSV导出。
- 手册：人工维护分类、步骤、复核要点及参考来源。

## 使用顺序

管理员新建巡检员/值班长后，进入“权限与区域”分配区域，否则该用户没有业务数据访问权限。节点页面配置该区域的告警规则，再模拟气体或温度异常。告警可建工单，值班长派给该区域巡检员；巡检员登录接单、处理、上传照片并提交；值班长复核。

巡检计划第一次到期默认为创建时刻，后台约30秒检查一次，之后按配置小时数生成；可停用计划。自动逾期提醒每个工单、每位接收者只发送一次。模拟器只在页面打开并启用时每15秒产生正常数据，单次场景按钮立即产生数据；不是后台硬件数据流。

## 数据与查询范围

- 日期使用采集时间和接收时间分别保存，采集时间按秒规范化；旧数据保存至历史，不逆转实时告警。
- 连续告警要求窗口内读数持续超过阈值，采样间隔不超过三倍节点上报周期。
- 无上报记录的节点显示“无数据”；有记录后超过三倍上报周期显示离线。
- 列表为最近500条工单/告警、300次巡检、200条通知、1000条审计；历史查询最多5000条、最大30天。
- 报表默认最近30天，可选1秒至366天；导出超过10000条会要求缩小范围，不会静默截断。
- 附件本地保存在 `.data/uploads/`，需与数据库一起备份。单张最多5MB，工单支持PNG/JPEG/WebP，巡检照片支持PNG/JPEG。
- JWT有效期一小时；新登录会话保存在数据库，可在个人设置撤销其他设备，会话校验包括账号禁用、过期和15/30/60分钟无操作超时。修改本人密码会撤销其他设备。迁移前签发的旧令牌按原一小时有效期自然到期。尚未实现刷新令牌和短信/邮件通知。

## 验证

```powershell
./mvnw.cmd test package
./scripts/verify-business.ps1 -BaseUrl http://localhost:18081
./scripts/verify-boundaries.ps1 -BaseUrl http://localhost:18081
$env:API_BASE='http://localhost:18081/api'
node ./scripts/verify-extended.mjs
```

集成脚本使用本机演示管理员，会产生明确带“验证”标识的业务记录和测试账号；执行结束后停用测试账号与计划。不要在生产数据库运行。浏览器验证脚本位于前端 `scripts/`，默认使用本机5174端口、Edge无头模式；测试服务需允许 `http://127.0.0.1:5174` 跨域。
